### 🎗️ Featured Project: Survival Analysis for Breast Cancer in Zimbabwe
**Chitungwiza Central Hospital (2013-2019) - Midlands State University**

- Analyzed 1,293 breast cancer cases out of 11,757 cancer records
- Used Kaplan-Meier curves, Log-Rank Test, Cox Proportional Hazards model
- Found Age 41-50 (p=0.0038) and 61-70 (p=0.0449) significantly associated with survival
- HR increases with age (HR=3.27 for 81-90)
- Tools: R (survival, survminer), SPSS v22, Excel
